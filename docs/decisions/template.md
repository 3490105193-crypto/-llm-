# ADR Template

## Status

## Context

Describe the product, technical, and operational forces behind the decision.

## Decision

State the chosen direction.

## Alternatives

List the serious alternatives considered.

## Tradeoffs

Explain what the decision optimizes for and what it gives up.

## Consequences

Describe the follow-up work, risks, migration concerns, and long-term implications.
